# Paramjit Singh Rana — Portfolio

Static one-page portfolio (HTML, CSS, vanilla JS — no build step).

- `index.html` — content
- `styles.css` — design (colours as CSS variables at the top)
- `script.js` — nav, scroll reveals, rotating role text

Preview locally: open `index.html` in a browser.
Deploy: GitHub Pages from the `main` branch root.
